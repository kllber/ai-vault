AI Vault · 密钥金库 —— 更新日志
================================================================
项目主页：https://github.com/kllber/ai-vault


## v1.0.0 —— 2026-10-05
首个正式版本。

【核心能力】
  - 金库即文件：数据保存为单个 .aivault 文件（类似 PSD），改动立即写盘、
    关闭软件前再保存一次；金库内容加密，可放网盘。
  - 加密存储：金库密码经 Argon2id（64 MiB / 3 轮）派生密钥，数据用
    AES-256-GCM 加密；明文密钥永不落盘、不上传。
  - 层级建模：厂商 → 账号 → 密钥；软件 → 项目；两者用「主用 / 备用」绑定。

【余额 / 花费 / 检测】
  - 余额与花费：DeepSeek、Moonshot、OpenRouter、硅基流动可直接查询；
    OpenAI / Anthropic 通过「管理密钥（Admin Key）」查本月花费；
    通义千问走官方 CLI（支持一键安装与一键登录）。
  - 有效性检测：逐把 key 调用免费接口判断是否失效。
  - 余额快照与趋势：仅在余额变化时记录，可查看真实曲线、日消耗、预计可用天数。

【桌面版】
  - Electron 桌面应用（Windows 10 / 11，免安装文件夹版，无需 .NET / Node / Python）。
  - 关闭窗口最小化到系统托盘继续运行；右键托盘图标可退出。
  - 支持开机自启动（设置里可开关）。
  - .aivault 文件专属图标，双击即可用本软件打开。
  - 设置页新增「关于」（版本 / 仓库 / 许可 / 作者）。

【手机端】
  - 内置本地服务：手机浏览器连同一 WiFi 即可使用；配合 Tailscale 可跨网络（异地）访问。
  - 支持“添加到主屏幕”（iOS / Android 桌面图标）。

【其它】
  - 多端自动同步（局域网内多设备共用同一份数据）。
  - 汇率自动获取；厂商 / 软件图标支持上传图片并裁切。
